# Data Contracts

This directory contains data schemas and contracts used between frontend and backend components.

## Structure

- `learner_profile/` - Learner data models
- `course_resource/` - Course and resource models
- `recommendation/` - Recommendation data structures
- `learning_path/` - Learning path models
- `feedback_event/` - Feedback and progress tracking
- `explanation/` - Explanation data models

## Usage

These contracts ensure consistent data structures across all components. Define schemas here before implementing in frontend or backend.
